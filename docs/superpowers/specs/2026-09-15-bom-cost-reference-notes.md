## 设备清单与计价范围

赤峰表 26-3，印刷 561–565 页 / PDF 573–577 页，字段为专业、设备名称、规格参数、单位、数量、单价、合价、备注。单价与合价均为人民币万元。

炉体成套价格可能包含钢结构、铜水套、耐火材料、溜槽等；部分风淬、热回收、制氧系统注明含安装。因此设备总成与其包含的部件不得重复累加，已含安装的价格不得再次套安装费。采购范围与报价来源应随行保存。

赤峰表 26-18，印刷 586 页起 / PDF 598 页起，采用系统、子项与费用构成多层汇总。系统包括原料储运、熔炼、吹炼、精炼、电解、阳极泥、烟尘回收、硫酸、渣选矿、公用工程等；费用构成为建筑、设备购置、安装、其他。

水口山第四章第 6 节及第七章表 7-2 至 7-7 区分利旧、改造、新增、更换，并记录能力复核结果。赤峰印刷 126 页 / PDF 138 页一次风机为两用一备：采购数量与运行数量不同，不能用所有设备的装机功率直接计算年电费。

## 投资与运营口径

赤峰第 2.4 节，印刷 51–52 页 / PDF 63–64 页，以及水口山第十四章，均分别计算：

- 建设投资＝工程费用＋工程建设其他费用＋预备费。
- 项目总投资＝建设投资＋建设期利息＋全额流动资金。
- 报批总投资＝建设投资＋建设期利息＋铺底流动资金。

两例铺底流动资金均为全额流动资金的 30%，这是可编辑的项目假设。水口山第十四章第 2.2.3 节的设备运杂费基数是出厂价，费率 6%；备件费为出厂价的 1%；预备费为工程与其他建设费用之和的 4%。赤峰第 26.5 节，印刷 577 页 / PDF 589 页，基本预备费率为 5.5%，未计涨价预备费。不同费用必须保存各自基数，不宜套用一个总费率。

赤峰第 26.2、26.5 节明确有范围外的外部道路、管线及政府建设的部分基础设施。项目范围缺项不能被表述为节省。

赤峰第 2.5 节和表 2-8，印刷 52–58 页 / PDF 64–70 页，年成本包含原辅料、燃料、动力、薪酬、折旧、修理及其他费用，余热发电抵减电费。水口山第十五章只计算改造后的增量成本。软件必须区分全厂与增量、一次建设投入与年度费用，不能相加为一个成本。

## 单位与价格

赤峰主成本表按含税价计算，水口山第十五章按不含税价计算。原料可能按湿矿、干矿或所含金属计价；贵金属使用 g、kg 等不同单位。年耗量还出现千 kWh、千 m³、万 Nm³ 等量纲，必须明确换算到元。

赤峰印刷 53–54 页 / PDF 65–66 页的进口精矿采用金属基准价、TC/RC、计价回收率、运费及交易损失，不能替换成无说明的普通吨矿单价。该报告电价 0.30 元/kWh 是当时地方优惠协议价；水口山表 15-1 电价 0.633 元/kWh（含税）来自业主，两者均不是当前市场通用报价。

## 优化边界与源表问题

赤峰印刷 75 页 / PDF 87 页及水口山第十六章第 4.2 节支持比较价差、产量、加工成本和建设投资变化。原料与产品价格可能相关；经营成本敏感性应避免重复计算原料价格变化。冻结基准的用量、单价与年时基后，才能比较候选投入的费用。总量相同不代表元素、热量、炉容和环保约束合格。

源表存在以下问题，应用必须保留校验与待核实状态：

- 赤峰表 26-3 第 11 行，两台设备乘 73.78 万元单价，合价仍写 73.78 万元，已核实原页。
- 赤峰表 26-10 与 26-18 的建筑、设备、安装拆分不同，工程总额却相同；不能混拼两表。
- 水口山表 14-1 百分比与金额不符；表 15-1 与 15-2 的粒煤、粉煤价格对应关系不同。
- 水口山表 16-7 出现建设投资增加而 IRR 上升的可疑结果，不宜直接移植。

计算应校验数量乘单价、明细与小计、总成重复计价、缺值与明确零值、单价单位、日期及税口径。未填金额显示未计价；已知金额只能标为已计价小计。
