# 富氧侧吹炉 VOF + 标准 k-ε 仿真设计

> 取代 `docs/superpowers/plans/2026-10-09-furnace-two-phase-demo.md` 的四面体演示方案。

## 目标

在前端 Web Worker 内完成可复算、守恒、压力收敛的三维气液两相计算，几分钟内给出趋势可信的准稳态结果，用于方案对比（半定量）。后处理为真实三维等值面与流线。页面只保留必要输入，数值参数集中在后台配置文件。

## 原方案的问题（2026-10-12 实测）

- `furnaceTetSolver.ts` 无 k-ε，动量缺对流与粘性项，用邻居平均代替；压力每步 4 次迭代，残差约 7.8e5 Pa，最大散度约 3e4 s⁻¹。
- `furnaceTetMesh.ts` 的六面体五分四面体不交替，相邻六面体共享面对不上：41,472 个边界面中 35,190 个在炉膛内部。目标网格数不生效，恒为 244,172。
- 三维显示是 10 张水平贴图叠加，最近点取值。

## 模块

所有计算代码位于 `frontend/src/utils/furnaceSim/`，均为纯函数或无 DOM 依赖的类，可在 Node 中测试。

| 文件 | 职责 |
| --- | --- |

| `furnaceSim/mesh.ts` | 渐变张量积六面体网格、切割单元体积分数与面开口率、风口入口面、烟道出口面、质量统计、连通性 |
| `furnaceSim/pressure.ts` | 变系数泊松方程，几何多重网格预条件共轭梯度（MGPCG） |
| `furnaceSim/vof.ts` | THINC 代数 VOF，方向分裂（Weymouth–Yue 守恒形式），输出质量通量 |
| `furnaceSim/momentum.ts` | 守恒形式动量预测，质量-动量一致输运，van Leer TVD，粘性，壁面函数阻力，平衡力重力 |
| `furnaceSim/turbulence.ts` | 标准 k-ε，壁面函数，入口湍流，有效粘度 |
| `furnaceSim/solver.ts` | 时间推进、Δt 控制、监控量、时均场、准稳态判据、发散检测 |

## 网格

- 张量积非均匀轴，锚点包括炉体端墙、直墙、炉顶、烟道边界、液面、风口端部和风口中心两侧。
- 尺寸函数 `s(x) = min(h, 加密尺寸 + (r-1)·距加密区距离)`，按 `∫dx/s` 均分节点，相邻比不超过 r（默认 1.18）。
- 基础尺寸 h 按档位目标流体单元数迭代反推，结果落在目标 ±25% 内。
- 切割单元：节点内外判断加子采样，得到体积分数 `vf` 与面开口率 `a`；`vf < 0.2` 视为固体；最大连通域外的碎片剔除。
- 风口：风口柱所在单元列从炉壁到端部设为固体，端部 Z 向面为入口面，开口率按圆盘与面相交面积并归一化，使总开口面积等于喷嘴面积，从而质量流量与动量通量精确。
- 出口：烟道顶部边界面，静压出口。

## 求解

MAC 交错网格，单元中心存 α、p_rgh、k、ε，面上存 u、v、w。每步：

1. VOF：按 x/y/z 轮换方向分裂，THINC（β=3.5）面通量，Weymouth–Yue 膨胀项保证守恒；得到面质量通量 `M = ρg·Q·Δt + (ρl-ρg)·F`。
2. 动量：交错控制体用相邻单元质量通量的平均做一致输运，`ρ^{n+1}V u* = ρ^n V u^n - Σ M u_f + Δt(粘性 + 重力)`；重力取平衡力形式 `-(g·x_f)∇ρ`；壁面函数作隐式阻力。
3. 压力：`∇·(a/ρ_f ∇p_rgh) = ∇·u*/Δt`，MGPCG，上一步解作初值，相对残差 1e-6；不收敛时报告并减半 Δt。
4. k-ε：质量通量迎风输运，生成项 `μt S²`（限幅 10ρε），耗散隐式线性化；壁面单元对数律固定 ε 并给出壁面生成项；入口 `k=1.5(IU)²`、`ε=Cμ^0.75 k^1.5/(0.07D)`。
5. Δt：按体积通量 CFL 0.5、面速度 CFL、扩散数控制，上限 2e-3 s。

## 后处理

- 等值面：气液界面（α，按速度着色）、速度模、湍动能、静压。
- 流线：风口端部与熔池内撒点，RK4 双向积分，按速度着色。
- 截面：任意轴向、可拖动，节点三线性插值着色。
- 色标统一为 turbo，范围取场的 1%～99% 分位数。

## 页面

参数（几何、氧气量、风口开闭、液面、氧枪高度、熔体密度）、网格（粗/中/细、生成、一行统计、显示网格）、计算（开始/暂停/重置、一行状态）、结果（显示内容、等值面/流线/截面、阈值、时均）。其余参数在 `furnaceSimConfig.ts`。

## 验证

网格档位与连通性、入口面积；静水平衡；溃坝（Martin & Moyce）；守恒与压力收敛；气量趋势；等值面球面积；均匀流流线；性能报告；`vite build`。

## 不包含

热耦合、化学反应、表面张力、气体随温度膨胀、多 Worker 并行、WebGPU。结果为半定量方案对比，不作为工业级 CFD 验证。
