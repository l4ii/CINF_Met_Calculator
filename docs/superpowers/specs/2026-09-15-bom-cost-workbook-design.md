# BOM 与工程造价工作簿设计

用户目标：优化富氧侧吹炉设备清单，工程造价采用 Excel Sheet 式分表，分别管理设备、建设材料和生产原料，并为后续算法调配原料降低成本预留可用的数据结构。

采用在现有铜熔炼、吹炼设备页面中扩展工作簿的方式；继续复用 React、ExcelJS、案例保存流程。不引入通用电子表格引擎，也不改变物料/热平衡求解器。

## 清单与计价边界

- BOM 增加设备编码、系统分类、来源和采购计价范围，补齐设计中已知的水套数量。保留选型计算来源，三维编辑尺寸不冒充已校核清单。
- 炉体成套范围内的水套、风口默认不重复收费；烟气接口默认不作为完整设备报价。用户可明确修改采购范围。
- 按工序保存已生成/编辑的 BOM 快照；清单、造价、导出和汇总引用同一份数据。重新生成按最新选型刷新清单；报价草稿按稳定 ID 保留。
- 修正吹炼参数变更错误清除熔炼完成标记的问题。

## 工作簿

底部工作表标签：费用汇总、设备购置、建设材料、安装工程、其他费用、生产原料、公辅能耗、产出货值、原料优化。

设备费用来自 BOM，可编辑数量、价格、采购范围、备注并补充设备。建设材料、安装、其他、公辅表可增删行，填写项目、单位、工程量/年用量、单价、来源备注。设备和建设材料报价不自动套用历史项目的旧价格。

金额统一内部人民币元，汇总显示万元。建设投资为设备+材料+安装+其他；年度运行费用为已有物料年费用+额外公辅年费用；两者不相加。建设期利息、流动资金及其他口径通过说明明确，用户可在其他表指定实际费用。空白/非法金额不当作有效零价，显示已计价小计与待补充数。产出货值差额仅作为物料、公辅层面的测算，不表述为利润。

按案例、工序存储工作簿。兼容旧案例已有年处理天数和物料单价；配料页保存也必须保留新工作簿和 BOM 快照。单价草稿和年处理天数新增工序覆盖，避免两个工序互相覆盖。

## 成本优化空间

保存当前投入的独立基准快照，包括稳定物料 ID、用量、单价、年运行小时；候选用量及上下限/锁定按 ID 保存。比较固定时基、固定价格下的年费用，检查数字、边界、锁定和总量。显示成本测算结果和工艺复核状态，不将未经过元素、物相、热平衡、炉容约束复核的结果称为可行最优配方。

支持导出候选输入 JSON 供后续算法接入；不自动回写生产配方。Excel 导出包含工作表、输入和公式，保留缺价标记及计价范围。

## 验证

独立手算样例验证金额、成套不重计、缺价与零价区别、建设/年度口径、基准不漂移、候选上下限。验证工序数据保存、BOM 导出/汇总一致性和 Excel 公式引用。执行前端构建与浏览器交互检查；记录仓库原有类型检查问题，不覆盖用户其他改动。

## 实施取舍

现有功能已有未提交实现，直接在当前工作区做局部修改，避免从旧提交建立分支漏掉现有造价功能。设计与实现均属本次用户请求授权的可逆本地工作，持续执行至可检查结果。
